# Chemistry 1 Learning App — Mission with Dr. Otter

**Topic:** Chemistry in Daily Life  
**Grade:** 11 – Academic (Medical)  
**Developed by:** Kate Eunice R. Callo  

Interactive tier-based mission. Fully client-side. Works on GitHub Pages.

## Features

- Learning objectives & competencies on the first screen  
- School logo support  
- Storyline with Dr. Otter (lab-gown otter mascot)  
- 7 unlockable tiers  
- Closed-ended activities only: Fact/Myth, multiple choice, sorting, matching  
- Floating mascot with scene changes + affirmations  
- Progress saved per student name (localStorage)  
- Full Mission Report at the end  

---

## Deploy on GitHub Pages

1. Upload all files to a public repository.  
2. Settings → Pages → Deploy from branch **main** → folder **/ (root)**.  
3. Open the published URL on any phone or computer.

No build step. No backend.
